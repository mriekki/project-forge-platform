# Coding / DSA Drills

Optional interview-style practice.

Preferred loop:

```text
problem
→ clarifying questions
→ approach
→ complexity
→ code
→ tests/edge cases
→ hints only when needed
→ alternatives
→ feedback
```

Patterns:

- arrays/strings,
- hash map/set,
- stack/queue,
- two pointers,
- sliding window,
- sorting,
- binary search,
- linked lists,
- trees,
- BFS/DFS,
- graph basics,
- recursion,
- Big-O.

Prefer project-themed exercises when practical.
