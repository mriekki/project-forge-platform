# Optional External Learning Resources

Prefer:

1. official docs,
2. official/vendor tutorials,
3. current high-quality videos,
4. interactive practice.

Show only 1–3 resources at a time.

Suggested source families:

- language/framework official docs,
- database vendor docs,
- MDN for web/HTTP,
- Docker docs,
- GitHub/Git docs,
- testing-framework docs,
- LeetCode or equivalent for targeted DSA/SQL practice.

When current web access is available, verify specific current video/tutorial
recommendations rather than relying on stale links.

External resources never become an engineering requirement.
